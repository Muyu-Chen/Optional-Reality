# Optional Reality

**Reality is optional. The laws of physics are yours to rewrite.**

Optional Reality is an experimental AI-powered physics sandbox where you can describe new physical laws in natural language and watch a simulated world react in real time.

## The Idea

What if gravity, friction, and even the way objects interact were just suggestions?

Instead of changing settings one slider at a time, imagine typing:

- "Make gravity pull everything to the left."
- "Let object A attract object B like a planet."
- "Whenever a blue ball hits a wall, split it into two."

The goal is to translate these instructions into structured rules that a 2D physics engine can apply to the simulation.

## Planned Features

- Interactive 2D playground with movable objects and obstacles
- Natural-language changes to physical properties such as gravity, mass, friction, and elasticity
- Custom rules for interactions between objects
- Real-time visualization of the results
- Reset and undo to experiment with different rules
