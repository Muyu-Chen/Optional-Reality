# 结算后的背景生命周期

星星结算面板出现后，背景生态继续沿用本轮最后的加速度运动：鸟、云、人车、水粒子和面包店窗外的生态不会因为游戏结束而冻结。出口吸入期间也连续运动；失败后的结果面板采用相同规则。

背景使用已有的独立固定步长模拟，不恢复玩法的 Matter 世界。结算星数、胜负、拾取、机关状态、指令历史、倒计时和实际角色位置保持结束时的结果；不会补拾星星或重复触发成功音效。

普通暂停、AI 等待和教学暂停仍冻结背景；页面隐藏和减少动态效果也停止背景推进。返回标签页不追赶后台经过的时间。重试恢复确定的初始背景，切关与销毁清理旧状态和 RAF。

`CanvasLab` 只决定独立背景是否活动。`AmbientScenery` 和 `LivingWorld` 保持运动逻辑与只读加速度接口，结束条件和评分仍由原游戏模块负责。回归测试同时观察真实生态坐标和不可变的玩法快照，覆盖几何关、面包店、成功、失败、隐藏、减少动态效果与重试。
