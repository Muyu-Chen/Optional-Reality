# 游戏呈现与动画约定

本页记录界面、场景动画与声音的职责。发布状态以 [部署记录](../deploy/live-game.md) 为准：第一轮结算、可读性与音乐版本 `7da00d4` 已上线；本轮新场景绘图、侧栏、生态、出口与音效仍待统一集成和发布验收。

## 界面与场景

- 暖纸面、深森林绿及有层次的游戏插画构成基底；前景物体、真实表面和机关应明显区别于背景装饰。
- 桌面消息正文和输入主要使用 18px，状态与辅助说明使用较小字号；窄屏按空间调整。Send now 和删除保持紧凑，不能因字号扩大遮挡出口。
- 蓝色表示弹性、青色表示摩擦、橙色表示推动、紫色表示加速度，金色表示收集物。配色、纹理和运动共同表达特性。
- 星星拾取反馈、HUD 与结算读取真实收集结果；减少动态效果时保留清楚的静态反馈。
- 背景生态只接收加速度、时间与可见性，不能创建物理碰撞体、改变星星或成功条件。鸟群、鹰与云的方向变化应平滑；暂停、隐藏和减少动态效果都停止其动态推进。
- 黑洞出口是过关后的呈现：物理世界先确认胜利，再使用复制的位置做吸入、缩小与结算衔接。动画不能延迟实际判胜、改变分数或再次消费消息；重试和切关清理旧过渡。

## 弹簧与面包机

几何弹簧采用单向接触下的胡克弹力及少量阻尼：落下压缩时连续减速，最大压缩处速度过零，弹簧伸展加速物体，离开后恢复重力飞行。平台跟随真实球底，不冻结小球、不瞬间设定发射速度。暂停不推进压缩状态，重试重新开始相同运动，反转加速度保留当下位置与速度。

没有预压或外力的弹簧不能让小球弹得比原始落点更高。若关卡需要预存能量，必须在配置和画面中明确体现，不能借动画凭空提高发射速度。

面包机是另一个有动力机关，继续采用约 0.6 秒蓄力后弹出的机制，并保留首次教学暂停。玩家只修改允许的规则，不需要输入 compress/release。

## 介绍页示意图

首页 hero SVG 保持原有构图。下方两块实验使用独立本地 Canvas：弹簧展示悬空、加重力、下落吃星、自然回弹、再次下落后反转与减速上升；轨道展示 A/B 椭圆运动和指向 A 的力。它们是示意图，不是可玩的关卡。

绘图使用真实 RAF 时间并限制长帧跳跃；离屏、隐藏与手动暂停均冻结时间。系统减少动态效果时显示原海报，Canvas 不支持或无 JavaScript 时也有海报。旧 GIF 资源保留，版本化模块由本站提供，不引入外部脚本。

## 声音

背景音乐已使用独立的原创 Web Audio 循环：首次可信操作后播放、低音量、可关闭并保存偏好；隐藏页面暂停，切关不叠加。

本轮音效按真实事件即时反馈星星、弹簧、规则确认与出口，使用独立开关，不能把音乐静音当成音效静音。未解锁的事件不排队，返回页面不补播旧事件；隐藏、静音、重试和卸载停止旧声音。浏览器不支持音频或存储失败不能影响游戏。音效的集成与实际听感尚需本轮统一验收。

浏览器验收应检查实际画面、遮挡、声音与减少动态效果；纯测试不能代替这些检查。测试入口见 [testing.md](./testing.md)。
