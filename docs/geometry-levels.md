# 几何物理关卡 — 02.3 至 02.5

三关位于基础反弹之后、面包店之前，已有 ID 不变。均使用 30 秒模拟时限，保留重力控制；规则通过队列准备，Send now 才执行。下面是可复现的普通通关解法；现在每关还有三颗星星，收齐并到达出口才获满分。符合物理的替代解法也接受。

| 关卡 / ID | 可复现操作 | 成功要求 |
| --- | --- | --- |
| 02.3 Not Too High / `multi-bounce` | `Set surface bounce to 0.9` 开始；第一次弹起后、第二次着地前发送 `Set surface bounce to 0.5` | 经两块蓝色板到达第二块上方出口；第二次过强会从出口上方经过 |
| 02.4 Brake Before the Edge / `friction-runway` | `Set surface friction to 0` 开始；在进入绿色区域前提前发送 `Set surface friction to 0.3` | 完整停在区域内，速度 ≤ 0.12 m/s，连续 0.75 秒 |
| 02.5 Catch Tutorial / `catch-cup` | 提前准备发射板 1.1、杯底 0，两条均可在第一次碰撞前发送 | 局部表面教学；完整收球后自动确认，速度 ≤ 0.15 m/s，连续 0.8 秒 |

接球杯定位为短教学，展示两个表面可以分别修改，不要求等到飞行中再发第二条。0.8 秒停留是避免擦边误判的自动确认，不作为独立的操作挑战。主线以同一规则在不同运动阶段的作用变化来设计，详见 [阶段式物理解谜](./phase-puzzles.md)。本页其余布局和物理验收记录仍对应现有版本。

## 视觉与物理

- 蓝色回弹纹随实际弹性变化；青色 **Grip surface（摩擦表面）** 使用固定颗粒纹理，摩擦越大，纹理越密、越明显。纹理位于真实表面厚度内，不使用传送带的方向箭头或滚动效果。普通墙为灰色，目标为绿色，底部掉落边界为红色。
- Grip surface 是固定表面，可改摩擦与弹性；例如 `Set grip surface friction to 0.3`。稳定对象 ID `runway` 和旧别名 `runway` / `跑道` 保留，已有消息继续可用。向右加速度属于环境，跑道本身没有电机或传送速度。
- 摩擦关是约束旋转的矩形滑块，使用实际法向接触冲量计算库仑摩擦；没有把静摩擦当成小球的滚动阻力。跑道右侧开放，场景没有隐形侧墙接住滑块。
- 接球杯的发射板与杯底有独立初始材质和别名，灰色杯壁为 preset。基础四种物理量均可用；通用弹性／摩擦指令影响全部可修改表面；用 launch pad / cup 指定目标则只修改对应表面。灰色杯壁仍保持固定材质。
- 杯底初始弹性 1.05，属于游戏允许的超弹性范围，回弹纹较大。降低杯底弹性不影响发射板，不在空中直接修改速度。
- 停靠目标用真实形状做完整包含检查，允许 0.5 世界像素的求解器接触穿透。仅触碰、高速经过、停在外面均不通关；离开或超速清零进度。绿色进度条反映真实停留时间，暂停冻结。

## 自动验证的容错

固定模拟频率为 120 Hz。下表记录实测窗口，不是玩家必须记住的参数。

| 条件 | 验证范围 |
| --- | --- |
| 第二次反弹前降弹性 | 起步后 tick 280、360、480、560 均通关，覆盖约 2.33 秒的发送窗口；不执行第二条并一直保持 0.9 时不通关 |
| 摩擦制动时机 | 滑块中心 x=300、330、360、400、430 制动均满星通关；首尾约 0.81 秒；过早 x=100 或过晚 x=500 制动不通关 |
| 摩擦强度 | 0.2、0.3、0.5、0.8 配合各自的提前制动距离均通关；保持 0 会经过目标并掉落 |
| 接球杯发射强度 | 1.05、1.075、1.1、1.125、1.15 均可配合杯底 0 通关 |
| 降低杯底弹性的时机 | tick 250、360、480、600 均通关；也允许提前准备并发送两条独立规则 |

默认状态八关均不误通关。测试还覆盖命名与中文别名、未知表面拒绝、保护滑块、局部规则独立、API 权限、连续停留、暂停、队列补位、真实字幕、失败后重试和下一关顺序。

## 代码边界

关卡文件只放数据。`scene-bodies.ts` 创建圆球/滑块和开放边界，`goal.ts` 判定目标，`command-parser.ts` 与 `command-compiler.ts` 按语法和场景别名解析目标。`geometry-renderer.ts` 组合 actor、surface、goal 三个独立绘图模块；运行时不按关卡 ID 写特殊通关逻辑。

执行 `npm test` 与 `npm run build`。完整记录见 [verification.md](./verification.md)，测试要求见 [testing.md](./testing.md)。

## 星星与满分路线

多次反弹的三颗星位于 [230,399]、[365,187]、[560,280]。先设置弹性 0.9，收取高弧线星星后把向下加速度改为 4，可以收齐并进入出口；tick 400–600 的多个采样时机均已验证。原先弹性 0.9 → 0.5 可普通通关，但该路线会漏星。

基础反弹使用地面星 [480,404]、高处星 [630,280]、出口前星 [665,230]。弹性 0 起步，在 x 约 490 时设置向上加速度 2 可满分；不同位置与强度组合也已测试。停车关需提前制动，继续滑过远端星后停稳；接球教学的三颗沿自然发射和接收路线摆放。完整九关说明见 [阶段式物理解谜](./phase-puzzles.md)。

Bank Shot 现为 02.1 碰撞教学，蓝色弹力地面关顺延为 02.2；关卡 ID、消息和成绩键保留。滑块摩擦的单位、停止距离和兼容验证见 [接触摩擦](./sliding-friction.md)。
