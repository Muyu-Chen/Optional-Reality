# 惯性与连续碰撞路线

在前一轮十五关基础上增加六关：运动章现在八关，碰撞章十关，机关章保持三关，共二十一关、六十三颗星。旧 ID、草稿和成绩键不变，没有新增物理引擎特例、限制编辑权限或直接操纵球体的规则。

| 编号 | 关卡 | 主要变化 | 推荐三星路线 |
| --- | --- | --- | --- |
| 01.6 | Thread the Gap / 穿过窄缝 | 上升、反向制动、无加速度滑行 | 向上 0.4；x340 左右反转；x580 左右关闭重力 |
| 01.7 | Down the Chimney / 对准竖井 | 同时制动与下落，单独关闭横向加速度 | Start；x300 施加左 0.5、下 0.4；对准开口、横向漂移接近零时设置右 0 |
| 01.8 | Hook Turn / 回勾 | 制动反向后再叠加另一个轴的加速度 | Start；x450 左 1；最远星附近开始返回时加上 0.4 |
| 02.8 | Double Bank / 双重反射 | 两次真实斜面碰撞，零重力改变方向 | 先设置表面弹性 1；右→上→右 |
| 02.9 | Low Roof / 碰顶软着陆 | 反弹、碰顶、接收面停车，三个独立接触 | 发射板弹性 0.9；着陆面弹性 0、摩擦 0.3，在首次反弹前准备好 |
| 02.10 | Mind the Gap / 惯性跨断桥 | 跑道加速、跨缝滑行、接触后制动 | 无摩擦且向右 0.8；跑道边缘关闭横向加速度；落入绿色区域后给着陆面摩擦 0.3 |

普通完成只需要出口，满分还需沿路线收齐星星。运动关没有新增机关；碰撞关保留命名表面与通用材质规则，因此可以通过不同强度或发送时机探索其他路线。低屋顶为预设表面，其他编辑限制来自已有真实权限数据。

验证使用真实 Matter 固定步长与玩家消息解析，不修改坐标、速度或评分。穿缝反转 x320–360、竖井制动 x280–320、回勾制动 x420–480、断桥撤除加速 x300–340 均有三星路线；双斜板弹性 0.9–1.1 均经过两块板且三星。屋顶路线检查发射板、屋顶、着陆面实际碰撞。省略后续规则的四个时序谜题不能完成推荐路线。

全关三星路线由 `client/src/test/level-solutions.ts` 记录有序玩家动作；`momentum-routes.test.ts` 覆盖窗口、必要性与接触事件，`expanded-levels.test.tsx` 覆盖真实队列、重试、成绩和下一关，`star-routes.test.ts` 回归全部二十一关。
