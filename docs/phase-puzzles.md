# 阶段式物理解谜

本轮设计方向：接球杯改为短教学；下一张主线关回到最早的「悬空小球、星星、弹簧、反转重力」。本文件是设计要求，星星收集与新弹簧关尚未实现；现有八关的布局记录见 [几何关卡说明](./geometry-levels.md)。

## 星星贯穿关卡

下一轮每关至少放置三颗可收集星星，短教学也遵循这个数量要求。星星是场景中的真实目标，各有位置与唯一 ID；碰到后消失，同一轮不重新生成。通过布局让收集贯穿不同运动阶段，而非把三颗挤在同一段必经直线上。

- 每颗星都有清楚的作用：引导一个运动阶段、提示路线变化，或给出阶段完成的反馈。教学可以沿宽容的自然路线摆放；三颗星不意味着三条指定指令或三次高难操作。
- 星星从开始就可见，HUD 显示 `Stars 0/3`（数量由关卡配置读取），出口显示尚缺的数量。收集后立即更新反馈，全部收集后出口亮起；触及已就绪的出口自动过关。
- 默认目标是收齐本关星星并到达出口；不要求按编号收集，不检查玩家是否使用了预设口令。允许同一次运动收取多颗，也允许改变路线后补收遗漏的星星。
- Try again 恢复本关所有星星和计数。星星不用于评价发消息多少、耗时或重试次数，也不循环刷新来延长关卡。
- 现有八关尚未接入星星；逐关改造时重新验证路线、可达性与通关条件，不能只在图上补三个图标就标记完成。

## 接球教学：两块表面，两条规则

学习目标是局部修改：发射板需要回弹，接收杯需要吸收碰撞。两条消息可以提前准备并在第一次碰撞前发出；教学不要求玩家假装等待某个精确时机。界面明确标为 Catch Tutorial。

星星接入时，教学的三颗分别沿发射后的上升段、向杯内下落的段落和杯内安全区放置，采用宽容的拾取范围。已学会两块表面设置后，玩家能顺着同一条清楚的路线收齐，不额外增加精确瞄准要求；布局需用真实模拟验证。

杯内低速持续 0.8 秒仍由程序自动确认，玩家不需要按住任何按钮。该确认只防止高速擦边误通关。后续可以把接球作为正式关卡的终点，不再单独反复考察停留。

## 第一张正式新关：One More Turn

场景保持几何风格：一个静止悬空的球，下方是固定蓝色弹簧，上方是绿色出口。初始重力为零。三颗星星分布在下落、弹起和改变重力后的路线中；出口显示收集要求，目标写明 Collect all 3 stars, then reach the exit。

| 星星 | 推荐位置 | 它提示的运动阶段 |
| --- | --- | --- |
| 第一颗 | 初始球下方、弹簧上方 | 先向下运动，沿途收集 |
| 第二颗 | 初始球上方、默认弹簧能到达的上升区 | 弹起后经过新的区域，初次下落时不会顺便收走 |
| 第三颗 | 默认反弹最高点之上、出口之前 | 需要进一步改变运动条件，延续向上的路线 |

这些位置用于引导理解，不绑定收集顺序或弹簧触发次数。星星的拾取范围与间距需提供宽容窗口；能通过合理的重力或惯性变化绕过弹簧并收齐的解法也接受。

| 阶段 | 玩家看到什么 | 玩家决定什么 | 世界反馈 |
| --- | --- | --- | --- |
| 观察 | 球悬空，三颗星星分布在不同高度，上方出口等待收齐 | 先让球向哪里运动 | 紫色重力箭头当前为空，目标路径可见，计数为 0/3 |
| 下落 | 发送 `add gravity` 后球加速向下 | 让球经过第一颗星星并接近弹簧 | 第一颗消失，计数为 1/3 |
| 蓄力 | 弹簧接住球，自动压缩约 0.6 秒 | 可以准备接下来的规则 | 托板下降、线圈压缩，再自动弹出；无需 compress/release 指令 |
| 回程 | 球向上弹起收取第二颗；向下的重力使它逐渐减速并回落，第三颗仍在更高处 | 发送 `reverse gravity`，让球到达第三颗与更高的出口 | 计数先变为 2/3；力箭头先反转，若球正向下运动，会先减速，再向上，保留速度连续性 |
| 完成 | 三颗星星全部收集，球进入上方出口 | 自动确认成功 | 计数为 3/3，出口即时响应，不额外增加停留要求 |

布局需保证默认弹簧在向下重力下达不到出口，玩家能看懂为何还要改规则。提示推荐在回落时反转重力，但提前在合适时机反转、关闭重力并利用惯性等有效解法也接受。系统不强制等待第二次下落，不靠禁止已学能力锁定解法。

如果第一次试玩发现反转只有极窄窗口，优先调整出口高度、场景间距与弹簧发射能量。允许玩家在暂停中准备消息，Send now 执行后观察变化。

## 后续关卡沿用同一种思考方式

| 候选 | 场景冲突 | 值得做出的选择 |
| --- | --- | --- |
| Leave the Ramp | 需要重力沿轨加速，离轨后继续下坠会错过出口 | 何时关闭重力，保留沿切线的惯性；现有首关作为参考 |
| One More Turn | 需要向下取星，弹起后向下重力又会把球拉回 | 何时改变重力方向，既收集又到达出口；优先实现 |
| Up, Then Through | 强反弹帮助越过高墙，后半段有可见的低矮通道 | 如何为两次接触安排不同材质；用于重做多次反弹，需先验证真实路线 |
| Carry, Then Stop | 光滑表面帮助跨过一段距离，进入终点后继续滑行会冲过边缘 | 何时增加摩擦，兼顾到达与停靠；现有摩擦跑道可继续打磨 |

正式关可以只使用两三种熟悉要素。前两张优先用重力、惯性和固定弹簧形成变化，再引入更复杂的活动机关。接球教学与基础反弹负责教会特性；通关挑战负责让这些特性在场景中产生选择。

## 实现与验收要求

- 关卡文件只配置球、轨道、星星列表、设备与目标；拾取、目标前置条件和弹簧运动在通用模块实现，运行层不按关卡 ID 特判。单独校验星星 ID 唯一、至少三颗、坐标有效；目标和 HUD 从同一列表计算总数。
- 星星采用真实接触拾取，一次收集后移除；未收齐触及出口不给成功，并显示剩余数量。允许玩家自行选择收集路线。
- 弹簧复用现有接触、蓄力、释放生命周期；几何绘图独立于面包店外壳。首次教学可解释自动蓄力，重试不重复强制打断。
- 初始静止、只添加重力、只反转重力等基线不能误通关。验证推荐解法的多个发送时机，以及物理上成立的替代解法。
- 验证重复接触不重复计数、同一步可拾取多颗、顺序变化、遗漏后补收、未收齐不能通关，以及每颗星在有效解法中可达。验证重试恢复全部星星与出口条件；暂停冻结拾取、蓄力和计时，迟到编译响应不能影响新一轮。
- 浏览器观察下落、压缩、弹起、减速、回落、反转后的运动，确认力箭头与运动方向的区别可读。自动测试通过后再确认是否有趣。
