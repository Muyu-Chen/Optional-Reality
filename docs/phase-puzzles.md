# 阶段式物理解谜

当前工作区已实现三个等级、十五个小关，每关三颗可收集星星；运动章五关、碰撞章七关、机关章三关。新增六关见 [运动与碰撞扩充](./motion-collision-expansion.md)。完整交互约定见 [星星评分、加速度与消息操作](./star-gameplay.md)，旧几何布局与普通通关窗口见 [几何关卡说明](./geometry-levels.md)。

## 通关与满分

到达出口即可通关；收齐本关全部星星再到达出口才是满分。HUD 和过关面板显示实际数量，星星不锁出口，不重新生成。Try again 恢复所有星星、世界和待发消息。

星星的位置定义空间目标。教学可以沿宽容路线摆放；正式关把星星放在不同运动区域，让玩家有理由重新选择规则。允许不同顺序、补收遗漏和物理上成立的替代路线，不检查是否输入了指定口令。

## 已实现的满分路线

| 关卡 | 满分思路 | 与普通通关的区别 |
| --- | --- | --- |
| Let It Roll | 添加向下加速度沿轨加速，离轨时关闭，沿惯性收齐三颗星 | 学会重力这个叫法对应竖直加速度，关闭后仍有速度 |
| One More Turn | 下落取星，被动弹簧自然压缩回弹，再反转竖直加速度取高处星并进入上方出口 | 直接向上飞也能到出口，但会漏掉下方星星 |
| Bring It Back | Start 放行初始漂移，在中间星附近施加向左加速度，惯性继续取远星后回程 | 太早制动仍能回出口，但会漏掉远星 |
| Over the Wall | 向上 0.2 抬升，在墙左沿附近反转重力，沿拱形轨迹取星再下降 | 普通过关的转向区间更宽；偏早、偏晚可能漏星 |
| The Side Door | 向右 0.15 绕出挡板，首星附近改为向左 0.15，保持下降并绕回左下出口 | 不改竖直速度；横向转弯过早或过晚会撞板、漏星或越界 |
| A Little More Bounce | 先设置低弹性，在即将触地或刚触地时向上加速，球继续扫过地面星再升向高星 | 弹性 0.9 可以一星通关；向上 1 不要等低星已收后再发送 |
| Not Too High | 高弹性取得第一段高弧线的星，再增大向下加速度，收齐出口上方的星并回到出口 | 原来的先高弹性、再低弹性保留为普通通关路线 |
| Brake Before the Edge | 沿跑道收齐，取得停车区远端星后再制动 | 提前停进停车区也能过关，但可能漏掉远端星 |
| Catch Tutorial | 发射板高弹性、杯底低弹性，两条可以提前设置，沿发射与接收路线收齐 | 用于局部表面教学；停稳由程序自动确认 |
| Bank Shot | 弹性 1，让斜板把水平运动反射向上，沿出射方向收星 | 弹性 0.5 可普通通关但漏星；0.8–1.1 多个强度可满分 |
| Return to Dock | 回弹墙弹性 0.9；滑块取得远星并反弹，回到停车区后加摩擦 | 去程停车也能过关，但会漏掉停车区以外的星星 |
| One Last Bounce | 地面弹性 0.9 起跳，在空中改为弹性 0、摩擦 0.3，下一次落地停稳 | 提前软化会停在左侧；一直高弹性则无法停进目标 |
| A Little Stored Energy / Catch the Breeze / The Last Order | 三颗沿传送、弹出、气流路线布置，已有可复现的设备组合可以收齐 | 继续承担设备教学与组合实验 |

## 弹簧关的运动过程

初始加速度为零，球静止悬空，蓝色弹簧在下方，绿色出口在上方。三颗星分别位于球下方和初始位置上方的两个高度。被动弹簧带有少量阻尼，不会把球弹得比原始下落高度更高；高处星需要玩家改变加速度。

1. `add gravity` 修改加速度向量的 y 分量，球向下收取第一颗。
2. 接触固定弹簧后，胡克弹力和阻尼连续作用。托板跟随球压低，球减速到零后回弹，脱离托板后仅受环境加速度影响；不重设速度，不需要 compress/release 指令。
3. 球自然弹起，向下加速度使它逐渐减速回落；这一次自然回弹不应取得高于起点的星。
4. `reverse gravity` 反转同一个 y 分量，球保留当前速度，先减速再改变运动方向，最终取得上方两颗星并进入出口。

推荐在回程反转，但提前改变规则或利用惯性等有效满分解法也接受。新关使用独立的几何弹簧绘图，连续接触力独立在 elastic-spring.ts，面包机仍使用有外部能源的定时发射行为。

## 已验证的路线窗口

固定模拟频率为 120 Hz。自动测试覆盖多次反弹在 tick 400、440、480、520、560、600 时把向下加速度从 2 改为 4，均可满分，首尾间隔约 1.67 秒。基础反弹覆盖多个起升位置与强度组合；弹簧关覆盖回落到 y=315、330、345、360、380 时反转的满分路线。具体测试在 `client/src/physics/star-routes.test.ts`。

基础反弹的教学路线使用弹性 0.1 与向上加速度 1：真实首次触地为 tick 314；在 tick 284、首次触地后的下一步、tick 332 发送均满分。低星会在发送后拾取；等 tick 344、低星已经拾取后才发送会错过高星。该窗口与过晚发送由 `client/src/physics/bounce-floor-timing.test.ts` 验证，教程和暂停菜单使用相同提示。

通用收集模块处理圆球与滑块的真实形状，并检查两帧之间的扫过路径，防止快速运动漏收。星星与评分、绘图、HUD、关卡配置分别维护，不在运行层按关卡 ID 特判。
