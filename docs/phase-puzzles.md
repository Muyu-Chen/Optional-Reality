# 阶段式物理解谜

本轮设计方向：接球杯改为短教学；下一张主线关回到最早的「悬空小球、星星、弹簧、反转重力」。本文件是设计要求，星星收集与新弹簧关尚未实现；现有八关的布局记录见 [几何关卡说明](./geometry-levels.md)。

## 接球教学：两块表面，两条规则

学习目标是局部修改：发射板需要回弹，接收杯需要吸收碰撞。两条消息可以提前准备并在第一次碰撞前发出；教学不要求玩家假装等待某个精确时机。界面明确标为 Catch Tutorial。

杯内低速持续 0.8 秒仍由程序自动确认，玩家不需要按住任何按钮。该确认只防止高速擦边误通关。后续可以把接球作为正式关卡的终点，不再单独反复考察停留。

## 第一张正式新关：One More Turn

场景保持几何风格：一个静止悬空的球，下方一颗星星，星星再下方是固定蓝色弹簧，上方是绿色出口。初始重力为零。星星与出口之间有可见的连接提示；目标写明 Collect the star, then reach the exit。

| 阶段 | 玩家看到什么 | 玩家决定什么 | 世界反馈 |
| --- | --- | --- | --- |
| 观察 | 球悬空，星星在下方，上方出口尚待收集星星 | 先让球向哪里运动 | 紫色重力箭头当前为空，目标路径可见 |
| 下落 | 发送 `add gravity` 后球加速向下 | 让球经过星星并接近弹簧 | 接触星星后星星消失，出口的星星标记亮起 |
| 蓄力 | 弹簧接住球，自动压缩约 0.6 秒 | 可以准备接下来的规则 | 托板下降、线圈压缩，再自动弹出；无需 compress/release 指令 |
| 回程 | 球向上弹起，向下的重力使它逐渐减速并回落 | 发送 `reverse gravity`，让球最终到达更高的出口 | 力箭头先反转；若球正向下运动，会先减速，再向上，保留速度连续性 |
| 完成 | 星星已收集，球进入上方出口 | 自动确认成功 | 出口即时响应，不额外增加停留要求 |

布局需保证默认弹簧在向下重力下达不到出口，玩家能看懂为何还要改规则。提示推荐在回落时反转重力，但提前在合适时机反转、关闭重力并利用惯性等有效解法也接受。系统不强制等待第二次下落，不靠禁止已学能力锁定解法。

如果第一次试玩发现反转只有极窄窗口，优先调整出口高度、场景间距与弹簧发射能量。允许玩家在暂停中准备消息，Send now 执行后观察变化。

## 后续关卡沿用同一种思考方式

| 候选 | 场景冲突 | 值得做出的选择 |
| --- | --- | --- |
| Leave the Ramp | 需要重力沿轨加速，离轨后继续下坠会错过出口 | 何时关闭重力，保留沿切线的惯性；现有首关作为参考 |
| One More Turn | 需要向下取星，弹起后向下重力又会把球拉回 | 何时改变重力方向，既收集又到达出口；优先实现 |
| Up, Then Through | 强反弹帮助越过高墙，后半段有可见的低矮通道 | 如何为两次接触安排不同材质；用于重做多次反弹，需先验证真实路线 |
| Carry, Then Stop | 光滑表面帮助跨过一段距离，进入终点后继续滑行会冲过边缘 | 何时增加摩擦，兼顾到达与停靠；现有摩擦跑道可继续打磨 |

正式关可以只使用两三种熟悉要素。前两张优先用重力、惯性和固定弹簧形成变化，再引入更复杂的活动机关。接球教学与基础反弹负责教会特性；通关挑战负责让这些特性在场景中产生选择。

## 实现与验收要求

- 关卡文件只配置球、轨道、收集物、设备与目标；拾取、目标前置条件和弹簧运动在通用模块实现，运行层不按关卡 ID 特判。
- 星星采用真实接触拾取，一次收集后移除；未收集触及出口不给成功，且有明确反馈。允许玩家自行选择收集路线。
- 弹簧复用现有接触、蓄力、释放生命周期；几何绘图独立于面包店外壳。首次教学可解释自动蓄力，重试不重复强制打断。
- 初始静止、只添加重力、只反转重力等基线不能误通关。验证推荐解法的多个发送时机，以及物理上成立的替代解法。
- 验证收集只触发一次，重试恢复星星与出口条件；暂停冻结蓄力和计时，迟到编译响应不能影响新一轮。
- 浏览器观察下落、压缩、弹起、减速、回落、反转后的运动，确认力箭头与运动方向的区别可读。自动测试通过后再确认是否有趣。
