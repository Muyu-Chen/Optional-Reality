# 阶段式物理解谜

已实现三个等级、九个小关，每关三颗可收集星星。完整交互约定见 [星星评分、加速度与消息操作](./star-gameplay.md)，旧几何布局与普通通关窗口见 [几何关卡说明](./geometry-levels.md)。

## 通关与满分

到达出口即可通关；收齐本关全部星星再到达出口才是满分。HUD 和过关面板显示实际数量，星星不锁出口，不重新生成。Try again 恢复所有星星、世界和待发消息。

星星的位置定义空间目标。教学可以沿宽容路线摆放；正式关把星星放在不同运动区域，让玩家有理由重新选择规则。允许不同顺序、补收遗漏和物理上成立的替代路线，不检查是否输入了指定口令。

## 已实现的满分路线

| 关卡 | 满分思路 | 与普通通关的区别 |
| --- | --- | --- |
| Gravity Lab | 添加向下加速度沿轨加速，离轨时关闭，沿惯性收齐三颗星 | 学会重力这个叫法对应竖直加速度，关闭后仍有速度 |
| One More Turn | 下落取星，固定弹簧自动蓄力弹出，再反转竖直加速度取高处星并进入上方出口 | 直接向上飞也能到出口，但会漏掉下方星星 |
| A Little More Bounce | 先低弹性收地面星，再向上加速收高处和出口旁的星 | 增大弹性可以直接通关，但会漏掉星星 |
| Not Too High | 高弹性取得第一段高弧线的星，再增大向下加速度，收齐出口上方的星并回到出口 | 原来的先高弹性、再低弹性保留为普通通关路线 |
| Brake Before the Edge | 沿跑道收齐，取得停车区远端星后再制动 | 提前停进停车区也能过关，但可能漏掉远端星 |
| Catch Tutorial | 发射板高弹性、杯底低弹性，两条可以提前设置，沿发射与接收路线收齐 | 用于局部表面教学；停稳由程序自动确认 |
| A Little Stored Energy / Catch the Breeze / The Last Order | 三颗沿传送、弹出、气流路线布置，已有可复现的设备组合可以收齐 | 继续承担设备教学与组合实验 |

## 弹簧关的运动过程

初始加速度为零，球静止悬空，蓝色弹簧在下方，绿色出口在上方。三颗星分别位于球下方、初始位置上方的反弹区、默认反弹高度以上。

1. `add gravity` 修改加速度向量的 y 分量，球向下收取第一颗。
2. 接触固定弹簧后自动蓄力 0.6 秒，托板与球一起压低，再自动弹出；不需要 compress/release 指令。
3. 球弹起取得第二颗，向下加速度使它逐渐减速回落。
4. `reverse gravity` 反转同一个 y 分量，球保留当前速度，先减速再改变运动方向，最终取得第三颗并进入出口。

推荐在回程反转，但提前改变规则或利用惯性等有效满分解法也接受。新关使用独立的几何弹簧绘图，物理仍复用通用设备生命周期。

## 已验证的路线窗口

固定模拟频率为 120 Hz。自动测试覆盖多次反弹在 tick 400、440、480、520、560、600 时把向下加速度从 2 改为 4，均可满分，首尾间隔约 1.67 秒。基础反弹覆盖多个起升位置与强度组合；弹簧关覆盖多个回落高度。具体测试在 `client/src/physics/star-routes.test.ts`。

通用收集模块处理圆球与滑块的真实形状，并检查两帧之间的扫过路径，防止快速运动漏收。星星与评分、绘图、HUD、关卡配置分别维护，不在运行层按关卡 ID 特判。
