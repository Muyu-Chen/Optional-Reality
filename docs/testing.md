# 测试要求与条件矩阵

运行 `npm ci`、`npm test`、`npm run build`。测试使用模拟 API，不读取 `.env` 中的密钥、不调用真实模型。Node.js 26 下当前为 **32 个测试文件、340 项测试**。GitHub Actions 在 push / pull request 时重复执行安装、测试、类型检查与生产构建。

## 覆盖条件

| 领域 | 正常路径 | 边界与异常 |
| --- | --- | --- |
| 队列 UI | 准备、单条/多选发送、补位、排序、历史与 Undo | 错误队首阻塞、24 条上限、满队列编辑、删除补位、清空时取消编辑、中文输入法与 Shift+Enter |
| AI 准备 | 自动解析、准备后手动执行、已解析操作重试复用 | 编辑/删除/清空/重试/切关/卸载时取消；旧响应或旧错误不能覆盖新请求；网络、HTTP、无效 JSON、无效规则与受保护目标 |
| 游戏流程 | 首发开始、暂停/恢复、教学 Continue、重试、重看教学 | API 等待与教学期间不推进；未开始时关闭菜单不自动开始；通关/超时/掉落后禁止发送；重试恢复世界、计时和额度 |
| 字幕 | 实际执行反馈、批量顺序展示 | 手动消息立即展示、5 秒计时不被新字幕重置、最多三组可见、卸载清理定时器 |
| 存储 | 按关卡保存草稿并重新本地解析 | 非数组、损坏 JSON、超长/非字符串记录、超量草稿、访问被拒绝或写入失败 |
| 规则 | 绝对/相对值、表面继承、权限、感应器去重 | 有限越界值限幅；非有限数/溢出拒绝、负零、初始快照严格校验、触发器总量上限、非法目标整批失败不修改原状态 |
| 消息理解 | 全关基础能力、水平加速度与重力独立、错词和限幅回显 | 不改数字/否定/ID，方向冲突与单位错误拒绝猜测；模型纠错保留、旧 API 结果仍在客户端限幅、Undo / 重试保留反馈 |
| 物理与机关 | 八个小关的可复现解法、Undo 与重试 | 不改规则不会误通关；出口边缘和最后一 tick；指令额度；风场正/负/零功率及边界；传送带必须接触地面；蓄力断电/释放时改功率/离开后重触发；撤销感应规则关门 |
| 几何新关 | 两次真实反弹、摩擦停车、独立杯底收球、多种强度和发送窗口 | 恒定弹性失败、过早/过晚制动、穿过目标不判胜、完整形状与连续低速、离开/超速清零、暂停冻结、重试清零、未知表面不退化为全局编辑、灰色杯壁与滑块保护 |
| 浏览器循环 | 30/60/144 FPS 下模拟时间一致、DPR 缩放 | 长帧补偿上限、暂停不累计时间、隐藏页面暂停、HUD 留白、销毁后清理动画/监听/观察器 |
| HTTP 与模型适配 | 真实本地 HTTP 路由和兼容格式 | 非 JSON/过大/非法请求、4 并发上限、失败/断开连接后释放槽位、每分钟限额边界、Origin；拒绝/截断/错误响应、供应商错误不泄漏响应体、取消/超时、配置限制 |

## 写新测试

- 按模块增加测试文件，条件表使用 `it.each`；每项测试验证可观察结果及失败后状态，避免大快照或仅验证实现细节。
- UI 测试使用 `game-harness.tsx` 挂载真实 React 界面和 Matter 世界，只替换绘图循环与网络。手动推进模拟时间、控制响应顺序，禁止依赖真实等待或真实模型。
- API mock 故意允许 abort 后仍返回，确保测试的是拒绝旧结果，而非只验证调用了 abort。
- 机关测试既验证触发，也验证不触发、取消、重触发和清理；修改关卡布局后保留稳定的通关与失败检查。
- 修改输入、队列和菜单时跑交互测试；修改规则、关卡或物理时跑物理测试；提交前跑完整套件和构建。

## 限制

这些检查降低回归风险，不能证明不存在缺陷。jsdom 不验证真实 Canvas 像素、CSS 遮挡和真实输入法；模拟服务不代表供应商实时行为。影响布局、绘图、输入法或 API 兼容性的改动仍需真实浏览器/设备验收，真实模型验收单独进行，参考 [验收记录](./verification.md)。
