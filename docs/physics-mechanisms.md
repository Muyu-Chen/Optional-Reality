# 物理机关与视觉语言提案

状态：机关库与后续关卡设计。曲面轨、基础反弹、多次反弹、青色摩擦跑道与接球杯已进入可玩目录，实际行为及验证见 [几何关卡说明](./geometry-levels.md)；其余候选仍为提案。面包店保留为后续主题实验。

下一轮优先级调整：接球杯作为局部材质短教学，主线已实现「落下取星 → 弹簧自动弹起 → 改变加速度到达出口」，具体路线见 [阶段式物理解谜](./phase-puzzles.md)。下面的机关库与候选顺序供选材使用；新增关卡先说明阶段冲突和玩家决策，再决定加入哪些机关。

已落地：弹性地板与弹簧使用蓝色，摩擦跑道使用青色粗糙纹，传送带和风场使用橙色方向提示，重力使用紫色。纹理跟随真实参数变化，零风力不画施力箭头；输入窗读取本关权限，设备独立标记 Editable / Preset。

## 先建立稳定的视觉语言

玩家首先应能看出「会发生什么」，然后用自然语言改变物理规则。颜色表示物理特性，同色在不同关卡保留同义；每种特性再配纹理、方向和状态动作。不能只靠颜色辨认，也不能给每种设备随意换一种颜色。

| 特性 | 颜色 | 几何/纹理 | 变化反馈 |
| --- | --- | --- | --- |
| 弹性、反弹 | 蓝色 | 弧形回弹纹、可压缩垫/线圈 | 弹性增强时回弹纹幅度增加；压缩与释放可见 |
| 主动推动、加速 | 橙色 | 连续方向箭头、运动条纹 | 箭头方向与实际施力一致；反转时箭头反向；停止时停止流动 |
| 摩擦、滑动阻力 | 青色 | 光滑平行线 ↔ 密集粗糙纹 | 摩擦增大时粗糙纹变密，滑动明显减速 |
| 重力方向/场 | 紫色 | 场边界与竖直力箭头 | 反转箭头；关闭时箭头消失，已有速度保留 |
| 普通结构 | 中性灰 | 实体墙、铰链、支撑点 | 不承担任务语义的背景保持低对比 |
| 目标 / 危险 | 绿色 / 红色 | 出口框 / 交叉警示纹 | 目标确认、失败边界清楚，保留形状与文字 |

同一块表面可以有多种性质。以色带、边缘纹理并列呈现「蓝色弹性 + 青色粗糙」，不把混合后的颜色作为第三种未知规则。数值变化不能让物理语义错位，例如「降低摩擦」不能画成会主动加速。

颜色与修改权限分开。蓝色说明物理特性，不自动代表本关允许修改；预设设备保留特性颜色，另显示 `Preset`。输入区域明确列出本关可修改的规则，选中/编译结果应能突出将受影响的表面或区域。不要把 `belt-main`、`spring_power` 当作玩家要学习的词汇。

## 十四种机关

### M01 曲面发射轨

- 外形：中性灰的 U 形轨道，紫色重力方向提示，离轨处轮廓清楚。
- 玩法：靠重力加速，再在合适时机关闭重力，沿切线飞向出口。
- 消息：`add gravity` → `stop gravity`，玩家手动选择两次发送时机。
- 变化：出口放在不同高度、增加上方挡板，不能靠一直保持某个重力通关。
- 基础：现有轨道和规则可复用，需验证布局和时机窗口。

### M02 蓝色反弹板

- 外形：蓝色弹性涂层与回弹纹，球碰撞时短暂压缩。
- 玩法：弹性决定反弹高度；过弱够不到，过强可能撞上限高结构。
- 消息：`Make the floor bouncier`，或明确指定弹性。
- 变化：水平地板、斜向反弹板、墙面；同样的蓝色始终表示反弹特性。
- 基础：现有 restitution 可复用。接触瞬间读取真实值，不在空中直接改变速度。

### M03 折返弹跳井

- 外形：首版为两块蓝色水平板，出口在第二块上侧；错位斜板与限高挡板作为后续变体。
- 玩法：先提高弹性，再降低弹性，避免第二次反弹从出口上方越过。
- 消息：两条弹性规则预先排队，分别在两次碰撞前发送。
- 变化：两次反弹逐步增加到三次；用几何形成不同反弹路线。
- 基础：主要是关卡布局，不需要创造新的物理属性。

### M04 青色制动跑道

- 外形：滑块进入水平跑道，青色粗糙纹标出接触区域，末端有明显断口。
- 玩法：先滑行，接近目标停靠区时增加摩擦，避免冲出断口。
- 消息：`Reduce floor friction` → `Increase floor friction`。
- 变化：可选择早刹车、晚刹车或分段减速；目标区足够宽。
- 基础：增加受保护滑块形状及停靠判定；滑块不能由模型直接移动。

### M05 材质斜坡

- 外形：同角度的光滑坡与粗糙坡，以青色纹理密度区分。
- 玩法：降低粗糙坡摩擦，让原本难以滑动的滑块下滑；后续在缓坡上重新增大摩擦。
- 消息：`Make the rough slope slippery`。
- 变化：两条路线，一个容易起步但难停，一个缓慢但容错大。
- 基础：明确表面的初始材质与目标别名，需要多表面初始值配置。

### M06 缓冲接球杯

- 外形：杯形目标，杯底有蓝色弹性衬垫，绿色目标框围住接收区域。
- 玩法：先借外部反弹板到达高处，再降低杯底弹性，避免落入后再次弹出。
- 消息：`Make the pad bouncier` → `Reduce the cup's bounce`。
- 变化：宽杯先教接收，窄杯再考察方向和能量。
- 基础：目标增加「停留一段时间」要求并显示确认进度，不能碰到边缘就提前判胜。

### M07 单向翻板

- 外形：带可见铰链与限位块的灰色薄板，旁边标明允许转动的方向。
- 玩法：从一侧能撞开，反向会被限位；用惯性穿过后再调整重力落到目标处。
- 消息：沿用重力、弹性规则，不新增抽象的开门命令。
- 变化：翻板可用来挡住回弹，形成物理单向路线。
- 基础：真实转动刚体、铰链与角度限位；不能只画翻板而用静态墙碰撞。

### M08 跷跷板

- 外形：支点、板身和重量分布都清晰；有弹性边缘时仍用蓝色标记。
- 玩法：落到一端产生转动，选择重力或碰撞变化的时机，使任务物体从另一端附近离开。
- 消息：沿用 `reverse gravity`、弹性调整。
- 变化：支点偏心、固定配重、不对称长度，先展示后增加组合。
- 基础：多刚体约束原型；质量与支点在场景中可读，不能要求玩家猜隐藏比例。

### M09 摆锤闸门

- 外形：灰色摆杆、明确的悬挂点，摆动范围和通行间隙可见。
- 玩法：调整重力改变摆动趋势，选择穿过间隙的时机。
- 消息：沿用重力方向或强度，不引入「暂停摆锤」的魔法命令。
- 变化：先单摆与宽间隙，再与蓝色弹板组合。
- 基础：需要验证周期、碰撞和通行窗口。关闭重力后摆锤仍有惯性，不能画成瞬间静止。

### M10 橙色旋转挡板

- 外形：橙色转动箭头和可见轴心，形状与碰撞体一致。
- 玩法：观察扫动方向，在宽窗口内让球穿过；进阶才开放转速或方向控制。
- 消息：先沿用重力；进阶 `Reverse the wheel`。
- 变化：单臂、双臂、错位旋转；避免用高速窄缝逼玩家拼一帧操作。
- 基础：当前圆形 rotor 的接触逻辑不能当成长条挡板；需要真实旋转形状。

### M11 蓝色压缩弹簧板

- 外形：裸露线圈、受压托板，全部沿用蓝色回弹语义，不包在面包机外壳里。
- 玩法：物体落上后自动压缩与释放；玩家改变弹簧能力或发射后的重力。
- 消息：`Increase spring strength`、`reverse gravity`。不要求 `compress and release`。
- 变化：落下收集星星 → 压缩 → 弹起 → 再次下落时反转重力，保留早期设想。
- 基础：可复用接触、蓄力、首次教学与取消事件；若改为真实刚度，需重新验证能量与释放行为。

### M12 铰接塌落桥

- 外形：桥面、铰链和支撑销可见；接触后支撑销脱开，桥面开始转动。
- 玩法：通过规则变化保持惯性跨过断口；桥面倒下会改变后续路线。
- 消息：沿用 `stop gravity` 或 `reverse gravity`。
- 变化：倒下的桥还可成为另一条斜坡，允许替代解法。
- 基础：脱销是预设机关事件，模型不判断「球上桥时」；形状和危险范围同步显示。

### M13 橙色风井

- 外形：有边界的淡橙色力场，箭头直接显示方向与作用区域；小风扇只是可选装饰。
- 玩法：风持续改变速度，把物体托起或推过断口，离开区域后仍保留惯性。
- 消息：`Increase the upward airflow`、`Reverse the airflow`。
- 变化：竖直风井、横向风道，先单场后组合。箭头体现连续施力，不暗示瞬移。
- 基础：现有向上风场可复用；横向需要配置明确的场向量与别名。不能把速度和加速度混为一个参数。

### M14 触碰开关与连线门

- 外形：触点与门之间始终有可见连线，激活后连线和门同步变亮。
- 玩法：用已有物理规则让物体碰到开关，再赶在后续路线变化前经过门。
- 消息：以已有重力/弹性操作为主；首次出现时默认已连线，后续才允许编排已有传感条件。
- 变化：侧墙触点、顶面触点、反弹后触点；接触位置可一眼辨认。
- 基础：可复用现有传感器开门。它是触碰开关，零重力下接触也会触发；不要用需要重量压下的视觉误导玩家。

## 下一轮关卡组合

| 顺序 | 暂定关名 | 组合 | 主要决策 |
| --- | --- | --- | --- |
| 01 | Leave the Ramp | 曲面轨 + 出口 | 离轨前后何时关闭重力 |
| 02 | A Little More Bounce | 蓝色弹板 + 高处出口 | 碰撞前准备合适弹性 |
| 03 | Not Too High | 两块弹板 + 顶板 | 两次碰撞使用不同弹性 |
| 04 | Brake Before the Edge | 滑块 + 青色跑道 | 摩擦何时增大，避免冲过目标 |
| 05 | Catch, Don't Bounce | 反弹板 + 接球杯 | 弹起后减小接收表面弹性 |
| 06 | Keep Your Momentum | 塌落桥 + 断口 | 把桥的变化与物体惯性组合 |
| 07 | An Open Moment | 摆锤/旋转挡板二选一 | 观察运动相位，再应用已准备规则 |
| 08 | One More Possibility | 弹板 + 风井 + 触碰门 | 最多三种熟悉机关，比较多种解法 |

03、04、05 的首个可玩版本已按 02.2、02.3、02.4 接入，已有 ID 与存储未改名。多次反弹用两块水平板与抬高出口呈现先强后弱，无需新增运动机关；06–08 仍待设计与验证。

## 物理语义与实现边界

- 首轮把规则词汇维持在重力、弹性、摩擦；新机关尽量复用规则，之后再引入弹簧与风场。关卡只介绍一个主要新概念，已学能力原则上保留。
- 允许符合规则的替代解法。若旧规则绕过新概念，应先调整几何与目标，而非不断增加隐蔽的只读权限。
- 关闭重力不会清除速度或角速度；反转重力不会让运动方向瞬间反转。弹性在碰撞时起作用，摩擦在接触时起作用，风场持续施加力。
- 摩擦教学优先使用滑块。理想无滑动滚动的小球，不能仅靠增大静摩擦就假定它会刹停；要教滚动阻力须单独建模并明确展示。
- 全局规则会影响场景中的全部相关物体。局部修改必须有可见区域/选中对象；多块蓝色板不能仅凭颜色猜目标，使用位置名称或选择高亮。
- 玩家只发送已经准备的简单规则。未来时机由玩家手动选择；提示不写模型尚不支持的自动条件句。
- 每种机关先验证不触发、触发、取消/重触发和重试清理，再验证目标路线；所有「可通关」仍以模拟测试和实际游玩为准。
- 关键时机窗口以约 1 秒以上为初始设计目标，再根据固定时间步测试调整；避免依赖一帧命中或精确背数值。
- 先落地统一的颜色、纹理、作用区与权限提示，再做新机关。界面可读性是关卡设计的前置要求。
