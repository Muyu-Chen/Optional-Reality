# 世界背景与游戏入口

背景成为能看出规则变化的生活世界，游戏拥有开始界面与独立关卡选择。装饰不改变关卡布局、规则权限和评分。当前工作区共十五关，新增内容见 [运动与碰撞扩充](./motion-collision-expansion.md)。

## 背景要求

- 场景铺满视口，使用天空、远景、地貌和近景形成层次；球、星星、轨道与出口始终优先可读。
- 正常向下加速度时，瀑布向下流、行人沿路走、汽车沿路开。加速度改变后，水流、贴地状态和运动方向给出对应反馈。
- 零重力开场可以使用宇宙空间；场景主题由关卡初始环境确定，执行规则时不突然换景。
- 每关各有独立的视觉配置，在统一画风下变化天空、远景和装饰；面包店保留机关与碰撞一致的室内结构。
- 瀑布采用简笔画的密集粒子水束与少量池面水花，淡水带保证连续性，避免把水画成散落的雨点。粒子的惯性与改向独立模拟，不能用箭头或突然转场代替。
- 背景装饰没有任务碰撞体，不进入模型的可编辑对象，也不影响拾取、命令额度或判胜。
- 背景模拟、布局和绘图分离，不逐帧写 React 状态。暂停、隐藏、减少动态效果、重试和卸载都有明确生命周期。

## 游戏入口要求

- 开始与选关画面呼应 [SBUHacks 2026 的 Steel and Steam 主题](https://hack.sbcs.io/)：黄铜、铜管、机械浮岛、压力表、齿轮与少量蒸汽。保持原创小球、星星和规则消息为主视觉，装饰不改变实际游戏界面和规则。
- `/demo/` 显示开始界面，可开始游戏、继续最近小关、进入关卡选择和调整声音。
- 关卡选择按 Motion、Collisions、Devices 展示十五关，分别为五、七、三关，关卡仍可自由探索；展示的信息必须来自实际配置与真实游玩记录。
- `?level=...` 保留直达关卡的行为；游戏菜单可以返回标题或进入独立选关页。
- “继续”恢复最近关卡入口和已存消息，不承诺恢复逐帧物理进度。
- 离开关卡时销毁旧世界并取消旧请求；返回后沿用现有的按关卡草稿。迟到响应不能执行到新场景。
- 关卡最佳星数仅在实际通关后更新，保留历史最高值；损坏或不可用的本地存储不阻止游玩。

## 音乐方向

保留原创本地 Web Audio 音乐，节奏更轻快、俏皮，使用短促电子音符和弹跳低音。只借鉴轻松休闲游戏的节奏感，不使用既有游戏旋律或外部音轨；音乐保持低音量，不能掩盖星星和操作反馈。音乐与音效仍可独立关闭，偏好、后台暂停和切关不叠加的约定保持一致。

本地只有简单解析可用时，应明确区分“指令缺少方向或单位”和“没有配置 AI”。开发预览可经 Vite 转发到现有后端，保持真实 key 留在服务器；不能悄悄回退到另一家服务的旧 key。
