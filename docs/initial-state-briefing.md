# 关卡初始状态提示

每次进入或重试关卡，在场景中间显示至少 5 秒的初始状态卡，再用 400 毫秒渐隐收起。主界面保持可操作；主动点击 Start 或成功发送第一条规则后立即收起，不额外等待。卡片本身不会启动世界或消耗 30 秒模拟时间。

- 显示球、滑块或面包的初始运动方向与速度，环境加速度的方向与数值，活动表面的初始弹性与摩擦，以及场景中机关的初始状态。
- 内容读取关卡配置，不读取队列里的待发送操作。速度使用配置中的 m/s；局部材质覆盖全局默认值，预设结构墙不挤占提示空间。
- 首访教学先显示，教学关闭后再开始提示的 5 秒。打开暂停菜单、教学或切到后台不消耗阅读／淡出时间。
- 鼠标悬停或键盘焦点在卡片内时保持显示；淡出中移回会恢复清晰，移开或焦点离开后重新等待完整 5 秒。隐藏卡片不会遗留悬停状态。
- 可以立即关闭，不移动输入焦点。切关、重试和卸载清理旧阅读／淡出计时器；减少动态效果时保留 5 秒阅读时间，直接收起，不播放入场或淡出动画。

职责划分：`levels/initial-state.ts` 生成展示数据，`game/useBriefingTimer.ts` 管理可见时间，`components/InitialStateBriefing.tsx` 和独立 CSS 负责展示。`Game` 只连接本轮 attempt、教学、暂停及运行状态，不修改物理引擎。

验证覆盖实际关卡配置、零值与斜向矢量、局部材质、机关状态、5 秒与淡出边界、悬停及移回、键盘焦点、首访教学、后台与菜单、准备与发送、重试、切关、减少动态效果和卸载。
