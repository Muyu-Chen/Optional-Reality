# 03.3 · Kiss of Steam / 单关快速试验

基于已合并的 `origin/main@294a172`，只给最后一关 `reality-breakdown` 增加可选的 2.5D 蒸汽汽车入口。其余八关、原面包店入口、AI 编译与主线进度保持原样。

```sh
npm ci
npm run dev:web
```

打开 `http://127.0.0.1:5173/demo/?level=reality-breakdown&experiment=steam-kiss`。也可在原最后一关的暂停菜单点 **Try 2.5D · Kiss of Steam**。删除 `experiment` 参数即可比较原关。

## 快速体验

- 直接发车：约 3.55 秒发生碰撞，看火花、蒸汽、碎片和车头的视觉压缩。
- 精确轻吻：先选「轻踩刹车」填写规则，发车后约 2.53–2.59 秒点击应用；建议使用 ×0.35 慢放。接触速度不高于 2.4 m/s，且低速稳定贴近至少 0.45 秒才成功。
- 提前制动会停得太远；全力制动配合低摩擦仍可能撞上。增加弹性会增强回弹。
- 点击配方只填写，点击应用或输入框回车才生效。支持所列中英文固定规则，不连接模型。
- 重试保留规则；恢复初始规则重建实验。Space 暂停，R 重试；隐藏标签页会暂停。

## 范围

这是原生 Canvas 的固定斜视角 2.5D 草模：立体车身、车轮、锅炉、路面、工业远景及粒子效果。没有新增渲染依赖。用一维固定步长刚体模型验证两车接近、摩擦制动和碰撞冲量：SI 单位、质量相同、动力与阻力连续积分，接触时根据相对速度和弹性计算动量交换。车头压缩与碎片为由真实碰撞触发的视觉效果，不是完整的可破坏车身模拟，未纳入主线星星评分。

`simulation.js` 管理规则和运动；`renderer.js` 只读物理状态；`main.js` 管理 UI、时钟、暂停与清理。CSS 全部限制在 `#steam-experiment` 内，不覆盖原游戏。
