Generated with built-in imagegen, using `../title-gameplay-v1.png` as the shared style reference. Six independently generated images; only transparent padding is cropped and assets resized/encoded as WebP. No objects are cut from a flattened illustration.

Browser: SVG layers animated by a deterministic timeline in `components/front-door/title-animation/scene.ts`. GIF export uses the same timeline and sprites.
